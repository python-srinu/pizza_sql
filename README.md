# 🍕 Pizza Sales SQL Project

Welcome to the **Pizza Sales SQL Project**! This repository provides a sample pizza sales database to help you practice and master SQL skills at beginner, intermediate, and advanced levels.

---

## 📁 Repository Structure

```bash
pizza_sales.zip
├── pizza_sales/
│   ├── orders.csv
│   ├── order_details.csv
│   ├── pizzas.csv
│   ├── pizza_types.csv
Pizza_Questions.txt
Pizza_Answers.sql.txt


---

## 🧾 Database Tables

The dataset contains the following CSV files representing key tables in a pizza ordering system:

- **orders**: Contains order dates and times.  
- **order_details**: Contains information about each pizza in an order.  
- **pizzas**: Contains pizza sizes, types, and prices.  
- **pizza_types**: Describes each pizza's category and ingredients.

---

## ❓ SQL Question Sets

The `Pizza_Questions.txt` file includes SQL questions grouped by difficulty level:

- **Beginner** – Basic `SELECT` statements, filters, and sorting.  
- **Intermediate** – `JOIN`s, aggregations, `GROUP BY`, and subqueries.  
- **Advanced** – Window functions, CTEs, and complex nested queries.

---

## ✅ Answers

The `Pizza_Answers.sql.txt` file provides corresponding SQL answers for each question.

Use these to verify your solutions or understand different approaches.

---

## 📦 Getting Started

1. **Unzip** `pizza_sales.zip` to extract the dataset.  
2. **Import** the CSV files into your SQL environment (e.g., SQLite, PostgreSQL, MySQL).  
3. **Start practicing** with the questions from `Pizza_Questions.txt`.  
4. **Check your answers** using `Pizza_Answers.sql.txt`.
